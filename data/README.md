# Data

Raw survey files are NOT committed to this repo due to licensing restrictions.
Download them manually and place them in `data/raw/`.

## Sources

### ANES (American National Election Studies)
- URL: https://electionstudies.org/data-center/2016-time-series-study/
- File needed: **"September 4, 2019 version" → DTA** (Stata format, no login required)
- Place in `data/raw/` — filename will be something like `anes_timeseries_2016_dta_20190904.dta`
- Key variables used:
  - `V161126` — 7-point liberal-conservative self-placement
  - `V162215` — trust in federal government
  - `V162216` — trust in Congress
  - `V162217` — trust in Supreme Court
  - `V162218` — trust in the news media
  - `V161155` — party identification (7-point)
  - `V162034a` — presidential vote choice

### Pew Research Political Typology (2021 or 2023)
- URL: https://www.pewresearch.org/politics/dataset/
- Note: requires free registration
- Provides pre-built ideological typology clusters useful for validation

### VOTER Survey (Democracy Fund + UCLA Nationscape)
- URL: https://www.voterstudygroup.org/data
- Key for: 2016 panel capturing 2012→2016 vote switching
- Enables direct identification of Bernie→Trump voters

## Processed Outputs

`data/processed/` contains JSON files generated by `src/process_anes.py`:

| File | Contents |
|---|---|
| `voters_2d.json` | One record per respondent: x (ideology), y (trust index), party, vote |
| `quadrant_summary.json` | Aggregate counts by quadrant × party × vote |
| `swing_voters.json` | Subset: voters who changed party vote 2012→2016 |
